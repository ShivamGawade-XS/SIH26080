# Flaw & Defect Register: Project Varsha

**Document Reference:** Varsha Triage and Flaw Tracker  
**Governing Rule:** Section 4.2 (Triage Protocol & Flaw Quotas)  
**Severity Definitions:**
- **S1 (Critical):** Wrong / misleading scientific result, data leakage, overclaim, crash on main path, legal/boundary defect.
- **S2 (Major):** Major usability defect, accessibility violation (serious/critical), broken documented command, medium security issue.
- **S3 (Moderate):** Minor visual polish, non-blocking UI inconsistency, performance optimization.
- **S4 (Minor):** Nice-to-have enhancement, documentation phrasing tweak.
