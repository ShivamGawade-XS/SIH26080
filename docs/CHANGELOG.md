## [0.1.0-alpha] - 2026-09-20

- **Repository Skeleton:** Structured package layout under `src/varsha/`, `configs/`, `tests/`, `scripts/`, `docs/`.
- **Open-Source Due Diligence:** Verified licenses for 44+ open-source components across subsystems S1–S13 (`docs/reuse/`).
